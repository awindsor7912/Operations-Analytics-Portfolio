## Invoice Adjustment Audit Dashboard

### Overview
This dashboard was developed to streamline and enhance the audit process for invoice adjustments by replacing manual tracking methods with an automated, data-driven solution. It provides both high-level insights and detailed transaction visibility, enabling efficient monitoring and validation of billing adjustments.

The report is built in Power BI and connects directly to a relational SQL data source, integrating multiple tables into a structured data model. A custom calendar table using DAX was implemented to support time-based analysis, including quarterly and year-to-date reporting.

---

### Key Features
- Direct integration with SQL data sources for automated, up-to-date reporting
- Relational data model combining multiple datasets for comprehensive analysis
- Interactive dashboard with filtering by date, area, billing code, and vendor
- Drill-through functionality to transition from summary visuals to detailed transaction-level data
- Exportable detail reports to support audit workflows and external review
- Time intelligence enabled through a DAX-based calendar table

---

### Impact
- Eliminated the need for manual Excel-based tracking and reporting
- Reduced time spent on audit preparation and data validation
- Improved accuracy and consistency of invoice adjustment tracking
- Increased visibility into adjustment trends, anomalies, and high-impact areas
- Enabled faster, more informed decision-making for billing and operations teams
